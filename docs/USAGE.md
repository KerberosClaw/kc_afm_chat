# 使用手冊

> English summary: Send with Return, insert a newline with Shift-Return, and attach
> one image by pasting, dropping or selecting it. Automatic compaction shows progress
> and keeps the full visible history. Stop saves received text once cancellation ends.

## 聊天與圖片

左上角按鈕或 ⌘N 新增對話。Return 送出，Shift Return 換行；中文輸入法選字中的
Return 只確認輸入。第一則訊息會成為預設標題。側欄可搜尋標題與訊息內容，右鍵選單
可重新命名或刪除；刪除前會再次確認。

圖片可用圖片按鈕選取、拖入視窗，或在輸入框貼上剪貼簿圖片。每則訊息一張，新的圖片
會取代尚未送出的附件。限制 20 MB、4,000 萬像素、單邊 16,384 像素；符合檔案限制
仍不保證模型上下文足夠。貼上時可能轉為 PNG；檔案選取與拖入保留原始位元組。
不輸入文字直接送圖時，預設請模型描述圖片。

回答串流顯示，可按停止。一次僅生成一則，期間仍可切換對話閱讀。草稿不保存，
切換對話會清除尚未送出的草稿及附件。每則完成的文字旁可複製內容。

## 自動整理對話

送出前會替回答預留空間，接近模型容量時自動開始整理。畫面顯示「正在整理對話…」，
成功後出現可展開摘要的「對話已整理」標記，再接續回答。優先保留最近一輪原文；
空間仍不足時連同該輪整理。圖片被整理後只保留文字已描述的資訊，不再次讀取舊圖。

原始聊天紀錄與圖片沒有因整理而刪除，但**模型這一輪只看到摘要與保留的近期內容**。
模型可能摘要錯誤或漏掉細節；重要資訊可以再次提供。圖片使用估算預算，實際容量
不足時會顯示錯誤；請縮短文字、換較小的圖，或另開對話。

整理途中停止或失敗，不會啟用未完成的摘要，原紀錄保留。未成功的回合不會送進
下一輪模型上下文。已停止的非空回覆會以中斷內容供後續參考。

## 保存、停止與異常

- 使用者訊息送出時寫入 JSONL。
- 回答完成、停止或可處理的錯誤發生後，保存已收到的內容及狀態。
- 超過 90 秒會要求取消；取消完成前不會開下一筆推論。
- 正常結束 App 會先要求停止並等待保存；強制結束或閃退不保證保存未完成串流。
- 上次回合中斷時，重開會顯示提示。既有完成內容仍可繼續使用。
- 保存回覆失敗時，暫存內容留在畫面，請先複製，再捨棄暫存內容繼續。

模型拒絕內容或回覆錯誤是可能的。App 不能上網查詢或執行指令；模型所寫的連結、
程式及事實沒有經過外部查證。資料恢復方式見[資料格式](DATA_FORMAT.md)。
